# Insightyfy

Insightlyfy is the solution that can convert raw data into pretty insightful dashboards- without the need to write a single line of code. This is a completely seamless and intelligent interface to upload the CSV file, with the automated processing, analysis, and visualization of the data using a combination of Python-based backend analysis to JavaScript-powered frontend interactivity.
It is endowed with a modern multistack architecture where the power of data processing comes from Flask, Pandas, and Matplotlib on the backend and the interactive capabilities use React, D3.js, and TypeScript at the frontend. The cloud hosting of Heroku gives zero-setup access from anywhere.
